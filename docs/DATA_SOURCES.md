# 数据来源与发布边界

## 开源交通 SQL 生成赛道

该赛道整理自公开 Text-to-SQL 数据集中的交通相关数据库和题目：

- Spider
- BIRD train

仓库保留原始来源、split 和题目修订记录。使用或再发布时，应同时遵守原数据集的许可证和引用要求。详细说明见 `tracks/open_source_sql/docs/OPEN_SOURCE_NOTES.md`。

## 上海交通业务分析赛道

该赛道基于上海多源交通数据构建专用评测数据库。数据库已统一时间字段、空间网格、交通方式指标和实体连接键，并移除采集过程、来源追踪和旧系统兼容字段。

公开发布前仍需确认：

1. 原始数据及衍生数据库的发布授权。
2. 是否包含可回溯个人、车辆或设备的信息。
3. 数据日期和空间精度是否符合公开要求。
4. 论文、仓库和数据库压缩包使用同一版本及校验值。

本仓库当前只把上海赛道标记为候选版本，不据此声明数据已获得公开发布授权。
